# Reading-path budgets
#
# The line counts `doc_citations::the_mandatory_reading_path_stays_small` enforces, and
# the reasoning for every raise each one has taken.
#
# ===========================================================================
# WHY THIS IS A DATA FILE AND NOT A `const` -- 2026-08-31
# ===========================================================================
#
# Doug: "It seems that we trigger a lot of full test runs because of that one file."
# He was right, and it was measurable. `gate_policy` sends any diff touching `src/` to
# the FULL gate, and these budgets lived in `src/doc_citations.rs` -- so a PURE PROSE
# commit that pushed a document over its budget became a `src/` change, and paid ~170 s
# instead of ~6 s. Two of the twenty commits pushed on 2026-08-31 were exactly that:
# a tour rewrite and a handoff note, each costing him about three minutes of waiting
# for a suite that could not observe the change.
#
# A budget is DATA ABOUT DOCUMENTS. It moves when a document moves, so it belongs on
# the docs side of the FAST/FULL line by nature and not merely for convenience. Moving
# it here makes the gate verdict correct rather than exempting anything: a prose commit
# that raises a budget is still a prose commit.
#
# **What was NOT done, and why.** The first idea was to exempt `doc_citations.rs` from
# the FULL gate outright, on the premise that all its tests are fast. Four of its 64 are
# slow-gated -- `tour_group_tables_match_the_real_equation_sheet` and three siblings
# compile a real specimen -- so that exemption would have skipped exactly the checks
# guarding `connect-expansion`'s tables. The premise was checked and was false. Editing
# a CHECKER in that file still means FULL, correctly; only the numbers moved.
#
# ---------------------------------------------------------------------------
# RULES
# ---------------------------------------------------------------------------
#
# Each entry is `name = lines`, and a name with no entry is a hard failure rather than a
# default -- an absent budget must never read as "no limit".
#
# **Raising a budget is allowed; raising it SILENTLY is not.** Every value here is set at
# the ACHIEVED line count, never with slack, because slack gets used. A raise lands in the
# same commit as the lines it buys, with the reasoning appended to that budget's block
# below. That history is the point of this file: it is the record of what each document
# was allowed to grow for.

# indistinguishable from a hang. Doug asked whether a session would discover

#

# …then 1931 → 1934 on 2026-08-25, for a new corollary of the absence rule:
# a stage's OUTCOME is a claim, and `Outcome::Failed` means "the pipeline

#

# and the enforcement on `the_corpus_outcome_matrix_is_unchanged`. It earns a
# raise rather than a trim elsewhere because it is a **binding rule with a
# checker**, not commentary: four separate sites had each violated it, and

# docs/README.md. The index is how a document is found at all, and an unindexed one is
# a document nobody reads — so the row is not optional. Recorded here because this is
# the first raise made under the new arrangement, and it is the shape every later one
# should have: the number moves in the same commit as the line it buys, and the reason

# **Owed work is the case this section exists for.** A `git log` reconstructs
