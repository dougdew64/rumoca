code never says what it is *for*.

## Authored to trigger

Two idealized proportional loops chained, the first loop's output driving the second's setpoint.

Authored to show that a system can hold **several independent simultaneous blocks**: loop A
depends on nothing but the reference, loop B depends on A but not the reverse, so structural
analysis finds two strongly-connected components rather than one.
