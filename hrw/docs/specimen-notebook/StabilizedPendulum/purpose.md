# StabilizedPendulum — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- StabilizedPendulum`, and
therefore correct by construction. What **cannot** be regenerated is why someone made this file —
the code never says what it is *for*.

## Authored to trigger

**The pendulum's index problem solved by the modeller instead of by the compiler.**

`CartesianPendulum` is index 3: the constraint `x^2 + y^2 = L^2` contains no derivative, so
nothing in the system determines `lambda` until the constraint is differentiated twice. Rumoca
does not implement general Pantelides, so it stops there. This file is the *other* way out, and
it is the way the field used before there was an algorithm: differentiate the constraint by hand,
and add feedback terms so the differentiated form does not drift away from the original one —

```
C = x^2 + y^2 - L^2,    Cdd + 2*alpha*Cd + beta^2*C = 0
```

published by Baumgarte in 1972, sixteen years before Pantelides. The resulting model is index 1
in the portable Modelica subset, with no compiler feature required.

It exists so the ladder has a rung between "index 3 is a wall" and "the compiler removes the
wall": **the wall was first climbed by hand**, and a reader can write that model themselves.

## What it found, 2026-09-24 — two walls, not one

Measured on Rumoca 0.9.20, and this was not the expected result:

```
Dae              Ok        4 state(s), 1 algebraic(s), 5 continuous equation(s)
Structural       Ok
IndexReduction   Ok        already index-1 — the reduction funnel is a no-op here
Initialization   Flagged   IC planning failed: structurally singular system: 0 matched
                           out of 1 equations and 1 unknowns; unmatched unknowns: lambda
Events           Ok
SolveLowering    Ok
simulation       FAILED    BDF: Failed to factorise matrix: SymbolicSingular { index: 4 }
```

**The hand reduction works.** Where `CartesianPendulum` reports `Structural … singular` and then
`still singular after index reduction`, this model passes both — and Rumoca correctly identifies
it as already index 1. That is a real confirmation that Baumgarte's 1972 construction does what
it claims, checked by a compiler that has no idea it was applied.

**And it still does not run.** Initialization cannot match `lambda` to an equation, so `lambda`
never receives a consistent initial value, and the solver's iteration matrix is singular at
index 4 — which is `lambda`, the fifth variable.

So Rumoca's inability to simulate a constrained pendulum is **not only** the missing Pantelides
implementation. There is a second, independent stop downstream, in initialization of an algebraic
unknown, and it is reached even when the index problem has already been removed. Naming only the
first would have been wrong, and this specimen is what made the second visible.

## Validated by the oracle first

Because the conclusion above blames Rumoca, the specimen was checked in **Wolfram System
Modeler** before anything was concluded (`WSMSimulate`, `{0, 2}`):

| t | `x` | `y` | `lambda` | `x^2+y^2-1` | `m(vx^2+vy^2-g*y)/L^2` |
|---|---|---|---|---|---|
| 0 | 1 | 0 | 0 | 0 | 0 |
| 0.25 | 0.9536646043 | −0.3008717467 | 8.854655724 | −1.5e−8 | 8.854655449 |
| 0.5 | 0.3910487904 | −0.920369948 | 27.08648745 | −2.4e−9 | 27.08648732 |
| 1.0 | −0.986291749 | −0.1650108656 | 4.856269462 | −2.8e−11 | 4.856269461 |
| 2.0 | 0.7935661992 | −0.6084839254 | 17.90768161 | −5.6e−12 | 17.90768161 |

Two things to read there. `lambda` agrees with the analytic tension `m(v^2 - g*y)/L^2` — the same
identity derived in [`dae-pendulum.md`](../../dae-pendulum.md) — to about 1e−9, so the physics is
the pendulum's and not an artefact of the stabilisation. And the constraint residual is **smaller
at t = 2 than at t = 0.25**, which is the whole purpose of the `alpha` and `beta` terms: an
unstabilised twice-differentiated constraint drifts, and this one is pulled back.

The model is therefore correct and portable. **The Rumoca failure is Rumoca's.**
