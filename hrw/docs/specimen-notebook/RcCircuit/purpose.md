# RcCircuit — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- RcCircuit`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

A constant voltage source driving a resistor into a capacitor, returned to ground.

Authored as the **initialization / IC planning** specimen — how Rumoca plans a consistent initial
state at t = 0 (`build_ic_plan`). Also the well-posed counterpart to
[`CapacitorLoop`](../CapacitorLoop/purpose.md): the same topology, one resistor away from
compiling.
