# RotationalInertia — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- RotationalInertia`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

The same physics as [`SingleInertia`](../SingleInertia/purpose.md) — one inertia under a constant
torque — but assembled from **MSL components wired by `connect`**.

Authored as the **connector expansion** contrast. Holding the physics fixed and changing only how
the model is written isolates exactly what `connect` adds: connection equations, flow sums, and
the resolve/instantiate work a hand-written model skips.
