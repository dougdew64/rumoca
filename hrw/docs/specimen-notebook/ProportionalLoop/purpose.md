code never says what it is *for*.

## Authored to trigger

An idealized proportional servo inner loop with every dynamic element removed, so every relation
is instantaneous.

Authored as the **algebraic loop** specimen: with no state to break the feedback, the loop closes
on itself and structural analysis produces one coupled block that must be torn. It is the
notebook's canonical 3x3 loop.
