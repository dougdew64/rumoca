# SingleInertia — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- SingleInertia`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

One rotating inertia driven by a constant torque, hand-written in the portable subset — no MSL,
no connectors.

Authored as the **smallest dynamic model** in the collection: the cleanest possible view of what
a *state* is and what the pipeline does to one. Every other specimen adds something to this.
