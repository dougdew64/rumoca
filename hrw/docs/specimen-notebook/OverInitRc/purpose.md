# OverInitRc — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- OverInitRc`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

The clean [`RcCircuit`](../RcCircuit/purpose.md) with two **conflicting** initial equations
bolted on: `C.v = 0` *and* `der(C.v) = 0`.

Authored as the **initialization over-determination** case, and deliberately separable: the
continuous model is perfectly well-posed and index-1. Only the initialization is broken, which
makes it a clean test of initialization determinacy rather than of structure.
