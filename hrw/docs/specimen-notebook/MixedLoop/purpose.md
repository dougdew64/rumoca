# MixedLoop — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- MixedLoop`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

[`ProportionalLoop`](../ProportionalLoop/purpose.md) with a scalar computation *bracketing* the
loop — a pre-scaled reference and a post-scaled output.

Authored to make **BLT ordering** visible. The earlier specimens are either all scalar or one
all-consuming coupled block; neither shows a system that mixes scalar solves with a simultaneous
block, which is what an ordering is *for*.
