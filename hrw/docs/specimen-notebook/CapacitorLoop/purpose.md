# CapacitorLoop — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- CapacitorLoop`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

A capacitor wired **directly across an ideal voltage source**, with no resistor.

Authored as the **blow-up** case — ill-posed, and *stays* ill-posed: it has one state, and index
reduction cannot rescue a single pinned state. Its deliberate pair is
[`RcCircuit`](../RcCircuit/purpose.md), the same topology with a resistor added, which compiles
cleanly. Loading the two back to back is the point.
