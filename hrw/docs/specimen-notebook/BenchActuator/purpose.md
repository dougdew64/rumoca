# BenchActuator — why this specimen exists

**Intent, not explanation.** *How* this specimen behaves is regenerated on demand from
[`trace/`](trace/) — generated by `cargo run -p hrw --example gen_trace -- BenchActuator`, and therefore
correct by construction. Prose about mechanism was retired 2026-07-29 (`docs/ideas.md` #42):
Claude reproduces it more accurately from the IR than from a stored copy nothing checks, and the
stored copies did go stale. What **cannot** be regenerated is why someone made this file — the
code never says what it is *for*.

## Authored to trigger

A DC motor spinning up an inertial load: `ConstantVoltage(12) → R(1Ω) → L(1e-4 H) →
RotationalEMF(k=0.1) → Inertia(J=0.05)`.

Authored as the **stiff** specimen — roughly a 1000x separation between the electrical time
constant (`L/R ≈ 1e-4 s`) and the rotor's spin-up. It is the first specimen meant to be *run*
rather than inspected, and the case where implicit BDF integration earns its keep.
